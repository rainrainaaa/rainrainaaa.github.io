⚡ SHORTCUT PENTING:

  Text Editor Tips:
    • Ctrl+H = Find & Replace (untuk ubah nama everywhere)
    • Ctrl+F = Find (cari sesuatu di file)
    • Ctrl+S = Save file

  Browser Tips:
    • F12 = Open DevTools (untuk inspect & debug)
    • F5 = Refresh halaman
    • Ctrl+Shift+Del = Clear cache
    • Ctrl+Shift+N = Incognito mode

  Python Server:
    • cd folder/tujuan
    • python -m http.server 8000
    • Buka: http://localhost:8000
