💡 PRO TIPS:

🎯 Editing HTML:
   • Gunakan VS Code (vscode.dev) - lebih mudah
   • Atau gunakan Notepad
   • Save file → Refresh browser (F5) untuk lihat changes

🎯 Testing:
   • Open DevTools: F12
   • Device Toolbar: Ctrl+Shift+M
   • Console: Lihat error messages
   • Clear Cache: Ctrl+Shift+Del

🎯 Images:
   • Compress dengan TinyPNG (tinypng.com)
   • Target < 100KB per image
   • Use high quality photos
   • Square ratio untuk profile pic

🎯 Colors:
   • Try COLOR_PRESETS.md untuk inspirasi
   • Default cyberpunk theme sudah keren!
   • Experiment dengan DevTools color picker

🎯 Fonts:
   • Orbitron untuk judul (futuristic)
   • Space Mono untuk body (technical)
   • Bisa ganti di Google Fonts link

🎯 Performance:
   • Minify CSS/JS untuk production (optional)
   • Use CDN untuk assets
   • Monitor dengan Google Lighthouse
   • Target: 90+ score
